# 編輯大事記

時間線位於技能與聯繫方式之間，是第 04 章。編輯 `src/data/timeline.ts` 即可調整內容；目前四筆都是明確的預留位置，沒有代填真實日期、學歷或經歷。

## 資料接口

`timelineEvents` 是 `TimelineEvent[]`，按陣列順序呈現，不會自動排序，也沒有四筆的數量限制。

| 欄位 | 用途 |
| --- | --- |
| `id` | 唯一且固定的識別碼，也是事件的 HTML ID；使用英數字與連字號，避免和章節 ID 重複。 |
| `dateLabel` | 畫面上的日期文字，例如「日期待填」或你確認後的日期。 |
| `dateTime?` | 選填的機器可讀日期：`YYYY`、`YYYY-MM` 或 `YYYY-MM-DD`。未填或空字串時只呈現文字，不輸出 `time` 或 `datetime`。 |
| `title` | 事件標題。 |
| `description` | 事件內容，例如背景、做了什麼，以及留下的收穫。 |

直接修改、新增或刪除陣列項目即可。日期請依實際精度填寫：只知道年份時，不必補出不存在的月份與日期。標題與說明以純文字輸出，不支援 HTML。

`timelineCopy` 控制章節標題、引言、預留說明與空狀態。內容填完後，可將 `note` 改成適合的補充文字或空字串，以移除預留說明。

## 版面與整合

`Timeline.astro` 提供完整的 `section#timeline`，主頁在技能章節後直接插入 `<Timeline />`。它也接受 `events` prop；傳入空陣列會顯示清楚的空狀態，不留下空白星軌。

桌機採左側主標、右側垂直事件列表；手機改為單欄。事件高度跟隨內容，增加文字或筆數會自然延伸章節，沿用網站既有的長章節閱讀方式，不使用固定高度、內層捲動或截字。沒有 JavaScript 時，標題與所有事件依然可讀。

標題容器與各事件提供 `data-reveal`，交由全站動畫統一處理；元件本身不啟動額外動畫或計時器。裝飾星圖、軌道與節點皆以 SVG／CSS 製作並從輔助科技隱藏，事件使用有序列表與 `h3` 標題維持閱讀結構。
