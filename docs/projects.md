# 專案展示與編輯指南

編輯 `src/data/projects.ts` 即可更新所有專案；這是靜態網站的資料接口，不是後端 API。先預留 10 個位置，不限制只能顯示 7 個或 10 個。

進入專案章節就能直接看到「單件主舞台＋全部作品索引」。不另外推薦三件作品，也不需要展開目錄。全部項目依資料順序排列，超出版面時以左右懸停、按鈕、鍵盤或觸控捲動索引。目前只有 PersonalWeb 是實際作品，其餘 9 個明確標為預留。

主舞台與索引共用同一份資料。點選索引才切換正在閱讀的作品，單純懸停縮圖不會突然換頁。關閉 JavaScript 時直接顯示全部作品文章，原生錨點連結仍可使用。舊的 `#project-archive` 網址保留為完整目錄的直接入口。

## 填入下一件作品

將陣列中的 `reserve('02')` 替換成下例，再修改內容。名稱、經歷與成績請填入真實資訊。

```ts
{
  id: 'project-02', // 每件作品唯一且穩定的英數 / 連字號 ID
  name: '你的專案名稱',
  subtitle: '一句話介紹這件作品',
  category: '專案類型',
  year: '2026',
  description: '背景、解決的問題、實作過程或成果。',
  role: '你在專案中的角色',
  tags: ['技術或工具'],
  status: 'published',
  visible: true,
  cover: {
    src: '/assets/your-project.webp',
    alt: '封面圖片的具體說明',
    fit: 'cover',
    position: 'center',
  },
  links: [
    { label: '體驗作品', href: 'https://example.com/' },
    { label: '查看原始碼', href: 'https://github.com/your-name/your-project' },
  ],
},
```

將圖片放在 `public/assets/`。資料中的 `/assets/...` 會自動補上 `/PersonalWeb/`，不用自行填入儲存庫名稱。圖片建議壓成 WebP，橫向比例約 16:9；透明背景物件或不宜裁切的截圖可使用 `fit: 'contain'`。沒有 `cover` 時顯示安靜的 CSS 星軌預留畫面，不顯示破圖。

可保留空字串或空陣列的欄位：`year`、`role`、`tags`、`links`。`description` 可以寫長文；舞台隨內容長度增高，不截斷說明。桌面整頁切換模式會先允許在長章節內捲動閱讀，到了邊界才在下一次新手勢切頁。`status: 'reserved'` 會明確顯示預留狀態，並隱藏外部連結。

## 新增、排序與隱藏

- 新增：在 `projects` 陣列後方加入同結構物件。選擇列、總數與鍵盤索引均從資料推導，無需修改元件或腳本。
- 排序：移動陣列項目的順序；畫面序號會自動重新編排。
- 顯示：全部 `visible: true` 的項目都會進入主舞台與索引；不再使用 `featured` 欄位，也沒有精選三件的限制。
- 暫時隱藏：將該物件的 `visible` 設成 `false`，或先移除未使用的 `reserve(...)`。
- 只剩一件或沒有溢出：自動隱藏左右捲動控制。
- 全部隱藏：展示留白提示，不初始化不存在的選擇器。

## 互動與效能

- 大圖主舞台只聚焦一件作品。縮圖 hover 不會突然替換正在閱讀的內容。
- 連續快速點擊採最後一次選取，不堆積動畫。切換以短距離平移與透明度完成，沒有持續背景動畫。
- 桌面兩側 hover 使用時間基準 `requestAnimationFrame`，有加速過渡；到邊界、游標離開、目錄捲出視窗、切換章節、分頁隱藏或失焦即停止，不使用常駐計時器。
- 觸控保留瀏覽器原生水平捲動；左右按鈕也可點按，不依賴 hover。
- 方向鍵、Home / End、空白鍵可選擇作品；焦點只調整選擇列的水平位置，不將整頁捲走。
- 觸控板水平捲動或 Shift + 滾輪只控制選擇列。普通上下滾輪遵循章節模式：桌面在完整作品庫內先捲動閱讀，到達邊界後的新手勢才切頁；手機等降級模式維持原生捲動。
- 返回專案章節或改變螢幕寬度時，保留已選中的作品並調整選擇列位置。
- 每件作品可用 `#project-panel-專案ID` 深連結；直接載入、改變網址片段或使用 Ctrl / Cmd 將縮圖另開分頁時，都會選中對應作品。點按／鍵盤選取同步以 `replaceState` 更新網址，不跳動整頁、不新增瀏覽歷史；重新整理不會回到較早的選取。
- 無 JavaScript 時直接顯示所有作品文章，索引使用原生錨點。開啟減少動態效果時取消自動 hover 和轉場，按鈕仍可用。
