# Orbital Atlas：個人星圖

本輪將夜海敘事改為一致的星空／星系語言，延續水墨版的互動與最新星海版的作品資料結構。不是另做一個只供展示的靜態 mockup。

## 視覺與參考界線

- 已唯讀查看使用者提供的 `C:\Users\User\fishs_web\personal_page` 專案，並在本機獨立預覽其建置版本。僅借鑑深藍、淡紫、暖金及星軌的氛圍；沒有複製該專案的程式、圖片、文字、人像、花草裝飾或游標效果。
- 自有方向是「個人星圖／觀測站」。首頁用傾斜的旋臂星系呈現想法的軌道；作品以座標與觀測框索引；技能串連不同探索方向；聯繫區以發送訊號收束。
- 四章共同使用深藍底、淡紫層次、香檳金細節與高對比文字。保留章節間深淺差異，但不再轉入白色頁面。
- 英文姓名使用 DM Serif Display，介面使用 DM Sans，中文使用 Noto Sans TC；字型失敗仍有系統字型 fallback。姓名與內容均為 HTML，不畫進圖片。
- 版型文字可後補。預留作品、技能方向不冒充真實成就。

## 原創資產

- `public/assets/orbital-atlas-v1.svg`：1600 × 1000，以確定性的數學旋臂、星點、漸層、星軌與行星繪製，無外部素材、無執行腳本、無字型依賴。首頁與 PersonalWeb 專案封面共用。
- `public/assets/orbital-atlas-social.png`：上述自有 SVG 的 1200 × 750 PNG 轉檔，供 Open Graph 分享，不作首頁下載。
- `src/components/StarField.astro`：建置時產生的靜態星點與星座；三章共用，不建立粒子迴圈。
- 技能／聯繫圖形與預留專案插畫均為原創 SVG／CSS。未引入 WebGL、GSAP 或動畫框架。
- 舊水墨與夜海資產、生成提示詞保留作歷史紀錄，新頁面不再引用。

## 功能與細節

- 桌面一幕一章、滾輪手勢鎖定、鍵盤切頁、快速導航最後目的地優先、錨點與上一頁／下一頁行為維持。
- 水墨版的右側章節索引、固定章節計數／進度、下一章與末章回開場已恢復。滾輪不循環回首頁。
- 保留三件精選、可展開完整作品庫、十個可擴充接口、兩側懸停捲動、觸控滑動、方向鍵選取、深連結與長文完整閱讀。
- 精選點擊後，對應頁籤會完整露在 header 與底部 dock 之間；直接開作品深連結仍優先閱讀作品標題。
- 手機、觸控、短視窗、減少動態效果採原生捲動。原生閱讀停止後同步章節 hash，但不覆寫專案深連結，也不新增歷史紀錄。
- 只有首頁三個星點微量閃爍與捲動退移；離屏、背景分頁時暫停，減少動態時完全停用。其餘宇宙裝飾靜態呈現。
- GitHub、Email 寄信／複製、無 JavaScript 導覽與完整作品閱讀均保留。

正式站只在 `main` 部署。星圖版本由 `feat/next-iteration` 提交後合併至 `main`，透過 GitHub Actions 執行型別檢查、建置與瀏覽器測試，通過後發布至 GitHub Pages。
